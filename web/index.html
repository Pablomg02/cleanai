      Frontera de Pareto

      Ningún otro modelo tiene a la vez más puntuación ponderada y mejor valor en el eje X.

        Cómo se calcula

        Cada criterio se lleva a 0–100: 0 es el peor modelo y 100 el mejor. Si en un criterio «menos es mejor», se invierte. Costes, tiempos y tokens se comparan en escala logarítmica.

        La puntuación es la media ponderada. Si a un modelo le falta un dato, ese criterio se ignora y su peso se reparte, salvo que actives «Dato que falta = 0».

        Nota 0–100 por grupo, relativa al dataset. Clic en una columna para ordenar; en una celda, para ver el detalle.
